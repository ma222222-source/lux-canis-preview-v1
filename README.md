# Lux Canis Preview v5

Cloudflare Pages Functions・D1・R2を使った運営対応版です。商品、写真、価格、公開状態、お知らせ、会員、問い合わせ、再販希望を共通データとして保存します。

## 運営画面

- `/admin.html` から管理者ログイン
- 商品の追加・編集・削除、写真アップロード、公開切り替え
- お知らせの追加・削除
- 会員、問い合わせ、再販希望の確認

管理者パスワードはCloudflareの `ADMIN_PASSWORD` シークレットで管理し、ソースコードには保存しません。

公開前に `node scripts/build-static.mjs` を実行し、`dist` をCloudflare Pagesへデプロイします。

Lux Canis（ルクス・カニス）の商品紹介・メルカリ誘導用デモサイトです。

## 確認方法

`index.html` をダブルクリックするとブラウザで開けます。外部ライブラリやインストール作業は不要です。

## 現在の仮表示

- 商品名
- 価格（`¥#,###`）
- メルカリURL

メルカリボタンは、URL未設定を案内するデモ動作です。

## 構成

- Hero
- 商品一覧・商品詳細モーダル
- カラーバリエーション
- ブランド紹介
- 購入案内
- メルカリ誘導

## V2デモで追加した機能

- ハンバーガーメニュー
- ピアス・イヤリング／ブレスレットのカテゴリ切替
- NEW・残りわずか・SOLD OUT表示
- 別ページの商品詳細
- カラー選択による商品写真切替
- メルカリ購入・再販通知のデモ導線

会員登録、問い合わせ送信、メール・プッシュ通知、管理画面はまだ外部サービスへ接続していません。

## V3デモ

- 会員登録・ログインの端末内デモ
- 通知設定の保存と対応ブラウザでのテスト通知
- 再販待ち登録・解除
- お問い合わせの入力・確認・受付完了
- お問い合わせと再販待ちが反映される管理画面デモ
- PWA用マニフェストとオフラインキャッシュ

個人情報をサーバーへ送信しない確認用デモです。メール送信・サーバープッシュ・本物の認証は未接続です。

## V4 表示・導線調整

- 通知設定とお知らせへの直接リンク
- スマホのマイページメニューを2列表示に変更
- パスワードの表示・非表示切替
- 通知拒否時の案内と無効状態を明確化
- 画面内のバージョン名・デモ表記を「プレビュー版」に統一
