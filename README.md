# Lux Canis Preview v1

Lux Canis（ルクス・カニス）の商品紹介・メルカリ誘導用デモサイトです。

## 確認方法

`index.html` をダブルクリックするとブラウザで開けます。外部ライブラリやインストール作業は不要です。

## 現在の仮表示

- 商品名
- 価格（`¥#,###`）
- メルカリURL

メルカリボタンは、URL未設定を案内するデモ動作です。

## 構成

- Hero
- 商品一覧・商品詳細モーダル
- カラーバリエーション
- ブランド紹介
- 購入案内
- メルカリ誘導
- PC・スマホ対応

## V2デモで追加した機能

- ハンバーガーメニュー
- ピアス・イヤリング／ブレスレットのカテゴリ切替
- NEW・残りわずか・SOLD OUT表示
- 別ページの商品詳細
- カラー選択による商品写真切替
- メルカリ購入・再販通知のデモ導線

会員登録、問い合わせ送信、メール・プッシュ通知、管理画面はまだ外部サービスへ接続していません。
